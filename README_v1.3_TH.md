# FRACTURED HORIZON — Prelude v1.3

## เปลี่ยนแปลง
- ปุ่มหลักใน Character Form เหลือปุ่มเดียว: **บันทึก PDF และส่งข้อมูลให้ GM**
- เมื่อกดจะเปิดหน้าต่างพิมพ์ ให้เลือก **Save as PDF** แล้วกดบันทึก
- หากผู้เล่นติ๊กยินยอม ระบบส่งข้อมูลส่วนที่แชร์ได้ไป Discord ผ่าน Cloudflare Worker URL เดิม
- ช่อง **ขอบเขตเนื้อเรื่อง** จะอยู่ใน PDF ส่วนตัว แต่ **ไม่ส่งไป Discord**
- เพิ่มคู่มือบริบทในทุกฉากของ Prelude และคำแนะนำก่อนกรอกฟอร์ม
- ปรับสำนวนบทนำ จุดอธิบาย The Dissonance และตอนจบให้อ่านเป็นธรรมชาติขึ้น
- ระบบเสียง ฉากหลัง อนิเมชัน และ Worker ยังคงเดิม

## วิธี Deploy
1. สำรองไฟล์เว็บไซต์เดิม รวมถึงเพลงของคุณใน `assets/audio/`
2. คัดลอกไฟล์เว็บเวอร์ชันนี้ขึ้น GitHub Pages (อย่าลบเพลงที่ใส่ไว้เอง)
3. ตรวจว่า `assets/discord-config.js` มี Worker URL ที่ใช้งานจริง
4. เปิด `character-form.html` กรอกทดลอง และติ๊กยินยอมส่งให้ GM
5. กด **บันทึก PDF และส่งข้อมูลให้ GM** เลือก Save as PDF ในหน้าต่างพิมพ์ แล้วตรวจข้อความใน Discord

## หมายเหตุ
- ด้วยข้อจำกัดของเบราว์เซอร์ เว็บไซต์จะเปิด **Print Dialog** ให้ผู้เล่นเลือก Save as PDF ไม่ใช่ดาวน์โหลด PDF อัตโนมัติแบบคลิกเดียวโดยไม่ต้องยืนยัน
- การส่ง Discord ยืนยันแยกจากการบันทึก PDF; หากเน็ตมีปัญหา PDF ยังบันทึกได้
- Endpoint สาธารณะอาจโดนสแปมได้ ควรเพิ่ม rate limiting / Turnstile ที่ Worker ก่อนเผยแพร่กว้าง
- ไฟล์เพลงใน ZIP นี้เป็น placeholder ขนาดศูนย์ไบต์ โปรดนำเพลงที่คุณใช้อยู่ใส่กลับก่อนอัปโหลด
