# VEYRA — Animated Interactive Prelude v0.6

เว็บไซต์ HTML แบบออฟไลน์สำหรับเปิดเรื่องราว Veyra ให้ผู้เล่นเลือกสำรวจโลก ก่อนสร้างตัวละคร Vestige

## การใช้งาน

1. แตก ZIP และเปิด `index.html` ในเบราว์เซอร์
2. เลือกสำรวจนครลูเมนฟอร์ด / เขตรอยค้าง / สถานีสัญญาณ
3. เมื่อไปถึงบทสรุป ให้กดสร้างตัวละครเพื่อเปิด `character-form.html`
4. หน้า Character Form มีฉาก `AUTHORIZATION IN PROGRESS` → `AUTHORIZATION COMPLETE` แล้วกด **เข้าสู่แบบฟอร์ม** (หรือข้ามได้)

## เพลงที่คุณเปลี่ยนได้เอง

- `assets/audio/bgm.mp3` = เพลง Prelude
- `assets/audio/form.mp3` = เพลง Character Form

ไฟล์ทั้งสองตั้งต้นเป็น **ไฟล์เปล่า 0 ไบต์** เพื่อให้ GM ใส่เพลงของตัวเอง ใช้ไฟล์ MP3 และชื่อเดิมแทนที่ได้เลย
หน้าเว็บพยายามเล่นเสียงทันที แต่ **Autoplay แบบมีเสียงถูกบล็อกในหลายเบราว์เซอร์** จึงมีปุ่มเปิดเพลงสำรอง
บนหน้า Character Form การคลิกปุ่ม `เข้าสู่แบบฟอร์ม` จะช่วยให้เริ่มเล่นเพลงได้อย่างถูกต้องตามข้อจำกัดของเบราว์เซอร์
ไม่สามารถรับประกันว่าการเปลี่ยนหน้าใหม่แล้วจะเปิดเพลงอัตโนมัติโดยไม่คลิกได้ทุกอุปกรณ์

## ปรับแต่งโค้ด

- `assets/story.js` — ข้อความและตัวเลือกทุกฉาก
- `assets/style.css` — ฉากหลัง SVG และ CSS animations ของเมือง/เขตรอยค้าง/สถานีสัญญาณ/ตอนจบ
- `assets/backgrounds/*.svg` — ภาพฉากหลังแต่ละภูมิภาค (เปลี่ยนเป็นภาพของตนเองได้)
- `assets/audio.js` — เปิด/ปิดเพลงและระดับเสียง
- `assets/authorization.js` — หน้าจอ Authorization ก่อนแบบฟอร์ม
- `assets/form.js` — เก็บ/ส่งออก Character Concept

## หมายเหตุ

Authorization เป็นแอนิเมชันในเรื่อง ไม่ใช่ระบบล็อกอินหรือการตรวจสอบตัวตนจริง
ลดเอฟเฟกต์การเคลื่อนไหวอัตโนมัติหากอุปกรณ์ผู้เล่นตั้งค่า `prefers-reduced-motion`
เพลงสองหน้าแยกกันและไม่ได้อัปโหลดข้อมูลผู้เล่นไปยังเซิร์ฟเวอร์โดยโค้ดนี้


## v0.7 — Obsidian Black Theme
ปรับโทนเว็บไซต์เป็นสีดำและเทาถ่านด้วย CSS ตอนท้ายของ `assets/style.css` โดยคงภาพพื้นหลังแบบเคลื่อนไหว ระบบเสียงสองหน้า เส้นทางสำรวจ และแบบฟอร์มเดิมทั้งหมดไว้ สีหลักแก้ได้ที่บล็อก `VEYRA v0.7 — OBSIDIAN BLACK THEME`


## v0.8 — หน้าแนะนำเปิดเสียงก่อนเริ่ม Prelude

- หน้าแรกมีหน้าต้อนรับ **FRACTURED HORIZON** เพื่อแนะนำให้ใช้หูฟังและเปิดเสียง
- ผู้เล่นกด **ยืนยัน เปิดเสียง และเข้าสู่เรื่องราว** เพื่อสั่ง `audio.play()` จากการคลิกจริง แล้วค่อยเปิดเนื้อเรื่อง
- ไม่มีการเล่นเสียงตั้งแต่โหลดหน้า การคลิกช่วยให้ผ่านข้อจำกัด Autoplay ของเบราว์เซอร์ได้มากที่สุด
- ไฟล์เพลงที่ต้องใส่เอง: `assets/audio/bgm.mp3` (เริ่มต้นเป็นไฟล์ว่าง 0 ไบต์)
- ถ้ายังไม่มีเพลง หรือการเล่นเสียงผิดพลาด จะมีปุ่มลองใหม่และ **เข้าสู่เว็บไซต์โดยไม่มีเสียง** เพื่อไม่ให้ผู้เล่นติดค้าง
- เพลงหน้า Character Form ยังคงใช้ `assets/audio/form.mp3` และระบบ Authorization เดิม
- เปลี่ยนชื่อหน้าต้อนรับเป็น FRACTURED HORIZON และเปลี่ยนภัยพิบัติใน Prelude เป็น The Dissonance
- แก้ข้อความหน้าต้อนรับที่ `index.html`, สีและแอนิเมชันที่ท้าย `assets/style.css`, ระบบเสียงที่ `assets/audio.js`


## v0.9 — แก้ไขปุ่มระดับเสียง Character Form

- ปรับ `assets/audio.js` ให้ตั้งค่าระดับเสียงและปุ่มเปิด/ปิดได้ทั้ง `index.html` และ `character-form.html` โดยไม่ผูกกับ Sound Gate
- หน้าฟอร์มใช้ไฟล์ `assets/audio/form.mp3` ส่วนหน้า Prelude ใช้ `assets/audio/bgm.mp3`
- `input[type=range]` ใช้ควบคุม `audio.volume` ตั้งแต่ 0 ถึง 100% ทันที
- ไฟล์เพลงที่เตรียมไว้ยังว่างอยู่ กรุณาใส่ MP3 จริงก่อนทดสอบการได้ยินเสียง


## v1.0 — ปรับ Lore ของ The Dissonance

- ชื่อแคมเปญ: **FRACTURED HORIZON** / ดาวเคราะห์: **Veyra**
- The Dissonance คือ **มหาภัยพิบัติ** ในอดีต ไม่ใช่ชื่อของเสียงผิดปกติทุกชนิดที่พบในปัจจุบัน
- เสียงที่แปลกประหลาดใน Aftertrace Zones คือ **เศษซากของเสียงที่ผิดเพี้ยนซึ่งหลงเหลือจากภัยพิบัติ**
- แก้เนื้อหาใน `assets/story.js` ให้สอดคล้องกัน โดยรักษาโครงสร้าง 35 ฉาก ตัวเลือก ภาพ อนิเมชัน Sound Gate เพลง และ Character Form เหมือนเดิม
- เพิ่ม `LORE_PLAYER.md` ซึ่งส่งให้ผู้เล่นอ่านได้โดยไม่เฉลยเรื่องหลัก
